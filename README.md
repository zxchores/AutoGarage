# AutoSpot

Flutter-приложение для авто-споттинга: камера, ИИ-распознавание, гараж, XP, рейтинг города и дуэли.

**Поставить на Android:** [инструкция и APK](INSTALL.md)

- [Универсальный APK](https://github.com/zxchores/AutoGarage/raw/main/releases/AutoSpot-1.0.0-android-universal.apk)
