# Установка AutoSpot на телефон

Тестовая сборка **v1.4.0** для Android.

## Скачать

[AutoSpot-1.4.0-android-arm64.apk](https://github.com/zxchores/AutoGarage/raw/main/autospot/releases/AutoSpot-1.4.0-android-arm64.apk) — почти все телефоны 2017+.

Старую версию удали перед установкой, если уже стояла 1.3.x.

## Как поставить

1. Скачай APK в Chrome на телефоне.
2. Открой файл → разреши установку из этого источника.
3. Если Play Защита ругается — «Подробнее» → «Всё равно установить».
4. На споте разреши камеру и геолокацию.

- Распознавание лучше читает кадр: меньше обрезки, крупнее JPEG, проще ответ модели, больше кодов вроде 320i/C200/X5
- Автопроверка новой APK в гараже и настройках
- Живые дуэли с игроками города, не только тренировка
- Серия спотов по дням, фильтры в гараже и дексе
- Охота района и выходные ивенты, серии BMW M / Tiggo / Vesta
- Чёрный X5 и белый X5 — разные карточки
- Клан, комментарии «видел такую», облачный аккаунт без фото
- Офлайн-очередь кадров, дроп легендарки, светлая тема и крупный шрифт
