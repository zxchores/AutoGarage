# Установка AutoSpot на телефон

Тестовая сборка **v1.0.0** для Android. iPhone так поставить нельзя: нужен Apple Developer и TestFlight.

## Какой файл качать

| Файл | Для кого |
|---|---|
| [AutoSpot-1.0.0-android-arm64.apk](https://github.com/zxchores/AutoGarage/raw/main/releases/AutoSpot-1.0.0-android-arm64.apk) | Почти все телефоны 2017+ (рекомендуется) |
| [AutoSpot-1.0.0-android-universal.apk](https://github.com/zxchores/AutoGarage/raw/main/releases/AutoSpot-1.0.0-android-universal.apk) | Если arm64 не ставится |

## Как поставить

1. Скачай APK на телефон (Chrome → ссылка выше).
2. Открой файл. Android спросит разрешение на установку из этого источника — разреши.
3. Нажми **Установить**.
4. При первом споте разреши **камеру** и при желании **геолокацию**.

Если пишет «заблокировано Play Защитой» — **Подробнее → Всё равно установить**. Это тестовая подпись, не магазин.

## Что проверить

1. Онбординг: ник и город.
2. Вкладка **Спот** → камера или галерея.
3. Карточка машины → **В гараж**.
4. Профиль, достижения, рейтинг города, дуэли.
5. Живой ИИ: Профиль → Настройки → ключ Gemini или OpenAI.

Без ключа работает демо-распознавание: одна и та же фотография даёт одну и ту же машину.
