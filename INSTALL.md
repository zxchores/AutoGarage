# Установка AutoSpot на телефон

Тестовая сборка **v1.3.0** для Android.

## Скачать

[AutoSpot-1.3.0-android-arm64.apk](https://github.com/zxchores/AutoGarage/raw/main/autospot/releases/AutoSpot-1.3.0-android-arm64.apk) — почти все телефоны 2017+.

Старую версию удали перед установкой, если уже стояла 1.2.x.

## Как поставить

1. Скачай APK в Chrome на телефоне.
2. Открой файл → разреши установку из этого источника.
3. Если Play Защита ругается — «Подробнее» → «Всё равно установить».
4. На споте разреши камеру и геолокацию.
