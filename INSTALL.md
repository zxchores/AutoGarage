# Установка AutoSpot на телефон

Тестовая сборка **v1.1.0** для Android.

## Скачать

[AutoSpot-1.1.0-android-arm64.apk](https://github.com/zxchores/AutoGarage/raw/main/releases/AutoSpot-1.1.0-android-arm64.apk) — почти все телефоны 2017+.

Старую версию удали перед установкой, если уже стояла 1.0.0.

## Как поставить

1. Скачай APK в Chrome на телефоне.
2. Открой файл → разреши установку из этого источника.
3. Если Play Защита ругается — «Подробнее» → «Всё равно установить».
4. На споте разреши камеру и геолокацию.

## Что нового

- Живая камера с рамкой и затвором
- Машину выбираешь из базы (картинка, имя, цена, редкость) — больше никакого рандома
- Кнопка «это не та модель»
- Первый экземпляр vs дубликат, охота дня, серии, карта спотов
- Дуэль из 3 машин, кулдаун, XP за бой
- Лидерборд: если игроков нет — ты первое место в городе
