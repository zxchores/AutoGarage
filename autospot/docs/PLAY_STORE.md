# Публикация AutoSpot в Google Play

Собрать `.aab` и пройти консоль можно только с вашего аккаунта разработчика. Ниже — готовый чеклист.

## 1. Аккаунт

1. [Google Play Console](https://play.google.com/console) — оплатите регистрацию разработчика.
2. Создайте приложение: название **AutoSpot**, язык по умолчанию русский.
3. Категория: «Образ жизни» или «Казуальные игры» (есть XP, дуэли, уровни — честнее как игра).
4. Загрузите политику конфиденциальности на сайт/GitHub Pages и вставьте URL. Текст: `docs/PRIVACY.md`.

## 2. Подпись Android

Сгенерируйте ключ один раз и храните его как пароль от банка:

```bash
keytool -genkey -v -keystore autospot-upload.jks -keyalg RSA -keysize 2048 -validity 10000 -alias upload
```

В `android/key.properties` (файл в git не коммитить):

```
storePassword=...
keyPassword=...
keyAlias=upload
storeFile=/absolute/path/autospot-upload.jks
```

Подключите `key.properties` в `android/app/build.gradle.kts` для `release` вместо debug-подписи.

## 3. Сборка

```bash
cd autospot
flutter pub get
flutter test
flutter build appbundle --release
```

Файл: `build/app/outputs/bundle/release/app-release.aab`.

Application id: `com.zxchores.autospot`. Если имя занято — смените в Gradle и манифесте.

## 4. Витрина

**Название:** AutoSpot — споттинг авто  
**Кратко:** Фотографируй машины, собирай гараж и соревнуйся в городе.  
**Полное описание:**

AutoSpot — коллекция автомобилей с улицы.

Сфотографируйте машину. Приложение определит марку, модель, заметный тюнинг и состояние, покажет ориентировочную стоимость из справочника и положит карточку в гараж.

- Редкость: Common, Rare, Epic, Legendary
- Опыт и уровни споттера
- Достижения вроде «Немецкая тройка» и «Ночной споттер»
- Рейтинг города
- Дуэли гаражей: редкость, цена, л.с., обвесы

Распознавание приблизительное. Это не база номеров и не оценка для продажи авто.

**Скриншоты:** телефон, 4–8 штук: онбординг, камера, карточка Epic, гараж, рейтинг, дуэль.  
**Иконка:** `assets/images/icon.png`.

## 5. Анкета доступа к данным

В консоли отметьте:

- Фото и видео — загружает пользователь, нужны для спота.
- Местоположение — приблизительно, только при споте, для города.
- Идентификаторы приложения — локальный профиль.

Не включайте «постоянное местоположение в фоне».

Data safety: данные не продаются, опционально уходят к Gemini/OpenAI только с ключом пользователя / вашей функции.

## 6. Тестирование

1. Внутреннее тестирование — вы сами.
2. Закрытый тест на 10–20 человек.
3. Продакшен.

Первая модерация занимает дни. Если отклонят из‑за камеры/гео — уточните формулировки: коллекция фото авто, не слежка за номерами.
