# AutoSpot

Мобильное MVP: фотографируешь машину → распознавание → карточка в гараж → XP, достижения, рейтинг города и дуэли гаражей.

Стек: **Flutter + Dart**, локальное хранение на устройстве, опционально **Gemini / OpenAI Vision**, заготовки под **Firebase**.

Приложение живёт в папке `autospot/`. Без Firebase и без ключа ИИ оно уже запускается: демо-режим стабильно «узнаёт» машину по самому кадру.

## Что уже есть

- Съёмка с камеры или выбор из галереи
- JSON-схема Vision API и разбор ответа
- Каталог из 690 уличных моделей: цена, л.с., 0–100, привод, редкость
- Гараж с карточками, XP, уровни, 10 достижений
- Рейтинг города и асинхронные дуэли по 4 метрикам
- Экран API-ключа (ключ только на устройстве)

## Запуск

Нужен [Flutter](https://docs.flutter.dev/get-started/install) 3.24+.

```bash
cd autospot
flutter pub get
flutter test
flutter run
```

На устройстве разрешите камеру и геолокацию. Город можно ввести руками.

### Живой ИИ вместо демо

1. Ключ [Google AI Studio](https://aistudio.google.com/) (Gemini) или OpenAI (`sk-...`).
2. Профиль → Настройки и API-ключ.
3. Следующий спот уйдёт в Vision API.

Цена, редкость и XP **не берутся из модели**. ИИ даёт марку/модель/тюнинг/состояние, справочник считает остальное.

Для магазина ключ нельзя оставлять в приложении — используйте Cloud Function из `firebase/functions`.

## Firebase (следующий шаг)

Коллекции:

| Коллекция | Зачем |
|---|---|
| `users/{uid}` | ник, город, XP, агрегаты гаража |
| `users/{uid}/garage_cars/{id}` | карточки спотов |
| `users/{uid}/achievements/{id}` | полученные бейджи |
| `city_leaderboards/{city}` | топ города (пишет только Functions) |
| `duels/{id}` | результаты дуэлей |

Правила и индексы лежат в `firebase/`. Фото — в Storage: `users/{uid}/spots/`.

## XP и редкость

- Common 15, Rare 40, Epic 90, Legendary 200
- Редкий тюнинг (обвес/винил) +25
- Удачный кадр +10 / +18
- Низкая уверенность ИИ ×0.5
- Повтор той же модели ×0.3
